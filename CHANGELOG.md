# Changelog

## 0.1.0

- Initial Bossbench developer release.
- Added core pg-boss/Postgres read model and pg-boss-backed actions.
- Added Hono and Express adapters.
- Added Workbench-style React dashboard using TanStack Router, React Query, Radix primitives, and pg-boss terminology.
- Added CLI initializer with Hono/Express detection, environment updates, package metadata updates, and route injection.
- Added unit, adapter, and real pg-boss/Postgres integration tests.
